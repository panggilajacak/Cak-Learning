## 📖 Tentang Proyek

**Cak Learning** adalah aplikasi web pembelajaran mandiri (*self-paced learning*) yang dirancang untuk memaksimalkan retensi ingatan melalui metode **Active Recall** dan **Spaced Repetition**. Aplikasi ini memadukan eksplorasi lintas disiplin ilmu dengan interaksi multimedia, mulai dari pemetaan bahasa daerah hingga simulasi berbasis kode yang dapat dikustomisasi secara bebas oleh pengguna.

---

## ✨ Fitur Utama

### 🗺️ Eksplorasi Bahasa & Peta Interaktif
* **Bahasa Daerah Nusantara:** Pelajari berbagai bahasa daerah (Jawa, Sunda, Batak, Bugis, Minang, Lampung, Madura, Papua, dan lainnya) yang dilengkapi dengan **peta interaktif Indonesia** serta formulir penambahan bahasa baru.
* **Bahasa Asing Populer:** Katalog 12 bahasa internasional lengkap dengan pemetaan titik wilayah (*region-point editing*) dan dukungan pencocokan suara (*voice matching*).

### 🧩 Manajemen Materi & Kustomisasi Fleksibel
* **Editor Sub-Materi Dinamis:** Susun materi secara fleksibel dengan dukungan teks panjang, estimasi waktu baca otomatis, pengaturan level materi, serta penyisipan gambar, file lampiran, animasi, dan kode simulasi interaktif.
* **Ekspor & Impor JSON:** Simpan, cadangkan, atau bagikan paket materi belajar dalam format `.json` dengan informasi kreator dan tautan referensi.
* **Pencarian Materi Cepat:** Temukan topik, sub-bab, atau kosakata secara instan melalui fitur pencarian terintegrasi.

### 🎧 Multimedia & Podcast Belajar
* **Katalog Podcast Terintegrasi:** Dengarkan materi audio dan podcast edukatif langsung di dalam aplikasi dengan dukungan pemutar alternatif (video & audio fallback) yang stabil.

### 🌐 Feed Materi & Interaksi Komunitas
* **Home Feed Materi:** Jelajahi materi yang dibagikan dengan sistem peringkat *upvote/downvote* (gaya Reddit).
* **Interaksi Sosial:** Fitur *Like*, komentar diskusi, dan tombol bagikan (*share*) untuk setiap materi pembelajaran.

### 📊 Pelacakan Progres & Motivasi
* **Indikator Level & Progres:** Pantau perkembangan belajar secara bertahap dilengkapi panduan *"Cara Belajar"* dan kutipan motivasi harian di bilah navigasi.

## 📚 Katalog Kurikulum

Cak Learning mengelompokkan materi ke dalam empat pilar utama:
1. **Bahasa Asing Populer** *(12 Bahasa Internasional)*
2. **Bahasa Daerah Nusantara** *(Eksplorasi Budaya & Linguistik Lokal)*
3. **Fundamental Penalaran & Kecerdasan Empati**
4. **Ilmu Lainnya** *(8 Bidang Wawasan Multidisiplin)* & **Skill Unik & Seni Berkomunikasi** *(11 Skill Praktis)*

## 🚀 Instalasi & Penggunaan

Ikuti langkah berikut untuk menjalankan **Cak Learning** secara lokal di komputer Anda:

1. Clone repository ini:
   ```bash
   git clone [https://github.com/panggilajacak/cak-learning.git](https://github.com/username-anda/cak-learning.git)

2. Masuk ke direktori proyek:
    ```bash
    cd cak-learning


3. Instal dependensi (jika menggunakan Node.js/bundler):
npm install

    ```Bash
    npm install

4. Jalankan aplikasi:
    ```Bash
    npm run dev
    
(Catatan: Jika aplikasi berbasis HTML/CSS/JS murni tanpa bundler, cukup buka file index.html langsung di browser atau gunakan ekstensi Live Server).
